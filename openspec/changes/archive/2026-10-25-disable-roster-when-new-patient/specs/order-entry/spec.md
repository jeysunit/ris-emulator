# Spec Delta

## MODIFIED Requirements

### Requirement: 予約作成の患者

予約作成の画面の「患者」は、「名簿から選ぶ」と「新規（架空）」のどちらかを選ばせなければ
ならない（SHALL）。「名簿から選ぶ」では、名簿（`orders.roster_path`）の患者を、患者 ID・
患者氏名・生年月日・性別を並べた選択肢から1人選ばせ、選んだ患者で予約を作る。
「新規（架空）」では、今と同じ規則（`docs/spec/01_orders.md` の 3.1）で架空の患者を1人作る。
「新規（架空）」を選んでいる間は、名簿の患者の選択肢を選べなくする。サーバーは、患者が
新規なら、名簿の患者 ID が送られても送られなくても使わない。
名簿が読めないときは、「名簿から選ぶ」を選べなくし、名簿が読めない理由を出す。

#### Scenario: 名簿の患者を選ぶ

- **WHEN** 利用者が「名簿から選ぶ」で患者 ID `P000002` の患者を選んで登録する
- **THEN** 作られた予約の患者 ID は `P000002`、患者氏名は名簿のその患者の氏名になる

#### Scenario: 新規の患者

- **WHEN** 利用者が「新規（架空）」を選んで登録する
- **THEN** データベースにまだない患者 ID の架空の患者で予約が作られる

#### Scenario: 新規を選んでいる間

- **WHEN** 利用者が「新規（架空）」を選ぶ
- **THEN** 名簿の患者の選択肢は選べなくなり、「名簿から選ぶ」に戻すと選べる

#### Scenario: 名簿を選んで送った後に名簿が読めなくなった

- **WHEN** 利用者が「名簿から選ぶ」で送り、そのときに名簿が読めない
- **THEN** 予約は作られず、画面は「名簿から選ぶ」「新規（架空）」のどちらも選ばれていない形で出る（黙って新規に切り替えない）
