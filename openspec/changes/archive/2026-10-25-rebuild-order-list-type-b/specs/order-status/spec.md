# order-status 仕様の差分

## MODIFIED Requirements

### Requirement: 画面は変更できる状態だけを選ばせる

Web 画面の予約の一覧の選んだ予約の区画と詳細は、今の状態と、今の状態から変更できる状態だけを選択肢に
出さなければならない（SHALL）。完了・取消・中止の予約には選択肢を出さず、状態の名前だけを
表示する。

#### Scenario: 予定の予約の選択肢

- **WHEN** 利用者が、予定の予約を一覧で選ぶ
- **THEN** 状態の選択肢は、予定・実施中・完了・取消の4つになる

#### Scenario: 実施中の予約の選択肢

- **WHEN** 利用者が、実施中の予約を一覧で選ぶ
- **THEN** 状態の選択肢は、予定・実施中・完了・取消・中止の5つになる

#### Scenario: 完了の予約の表示

- **WHEN** 利用者が、完了の予約の詳細を開く
- **THEN** 状態は「完了」と表示され、状態を変えるフォームは表示されない
